# WatchGuard v0.7.5 — Mobile drawer navigation

Watchlists now has its own full-width mobile drawer entry in both supported Jellyfin layouts, with native icon/text alignment, active state and drawer dismissal. Reopening the drawer and resizing preserve desktop navigation without duplicate entries. The v0.7.4 startup handoff and in-place filter navigation remain intact.

Release qualification now tests Jellyfin Server/Web 12.2.0 and 12.3.0 against one identical package in a single workflow. Publication waits for all 22 integration suites and a matching-commit/checksum evidence gate, including the full proxy matrix. ABI remains 12.2.0.0 with .NET 10.

See the [screenshots, qualification and limitations](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/drawer-qualification-v075.md).
