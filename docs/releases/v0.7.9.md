# WatchGuard v0.7.9 — Watchlists beside your native navigation

Watchlists now sits alongside Home and Favorites in Desktop Legacy and Mobile Legacy, with matching text size and spacing. The drawer keeps its own full-width entry, so opening it no longer moves the Legacy header navigation.

Native Home and Favorites retain their tab handling. Watchlists links, filters, browser history and the startup loading handoff continue to work with Auto and both Legacy layouts.

See the [installation guide](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/README.md) and [navigation validation](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/navigation-v079.md).
