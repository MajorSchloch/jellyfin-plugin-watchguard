# WatchGuard v0.7.10 — Navigation that fits Jellyfin

- Watchlists uses the native Modern navigation typography, button spacing, SVG icon structure and hover presentation.
- Watchlists appears with native navigation, independently of activity loading. Legacy tabs no longer shift when the activity runtime arrives.
- Navigation entries retain their identity through ordinary header updates, drawer opening and responsive changes.

Supports Jellyfin Server/Web 12.2, 12.3 and 12.4. Minimum ABI and dependencies remain 12.2. No additional browser runtime is installed.

See [navigation findings, measurements and limitations](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/navigation-v0710.md) and [protection boundaries](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/server-enforcement-v049.md).
