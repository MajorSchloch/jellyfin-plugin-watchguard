# WatchGuard v0.7.14 — responsive filters from the start

- Use status, sorting, activity range and search controls immediately after opening Watchlists without leaving the page stuck loading.
- Keep explicit URL values and your latest choices when saved defaults arrive.
- Keep controls, focus and open sections in place while the selected view loads. Filter changes do not save preferences automatically.

This patch preserves permissions, removal feedback, deletion protection, native history and Chromium 79 support.
