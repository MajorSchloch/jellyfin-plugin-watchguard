# WatchGuard v0.7.15 — return to your place in Watchlists

- Return from a movie or series to the originating title and approximate viewport position.
- Continue keyboard or TV remote navigation from the title action.
- Load current, authorized results within a fixed restoration budget. If the position is unavailable, keep normal loading and refresh controls.
- Stop automatic movement as soon as you interact with the returning view.

Deletion protection, approval permissions and personal data formats are unchanged.
