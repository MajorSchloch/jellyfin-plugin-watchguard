# WatchGuard v0.7.12 — older browsers and TV controls

- WatchGuard scripts can load on Chromium 79. Browser API and styling fallbacks keep the startup handoff, filters and status displays usable.
- TV users can reach disclosure controls with arrows, toggle status checkboxes with OK and close open filters or dialogs with Back.
- Detail watchlist actions regain focus as soon as membership changes finish, without waiting for the separate interest refresh.

Authentication, deletion protection and stored watchlists keep their existing rules. Compatibility with a particular TV application still depends on how it loads Jellyfin Web. Physical LG hardware validation remains necessary.
