# WatchGuard v0.7.2 — Keep filter changes in Watchlists

Owner, status, sorting, activity range, older interest, search and Reset to Defaults update the existing Watchlists view without asking Jellyfin to navigate through Home. Loading stays inside Watchlists, with keyboard focus and open controls retained. Reset remains focusable while its saved-preference request is pending and ignores repeated activation.

The URL continues to describe the selected view for sharing and reloading. Filter changes replace the current Watchlists history entry: Back returns to the previous page, and Forward restores the latest filters. Item details, Home and Favourites retain normal Jellyfin navigation.

Activity queries, saved-default semantics, authorization, polling and pagination limits are unchanged. Requires Jellyfin Server/Web 12.2.0 and .NET 10.

See the [navigation validation](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/navigation-validation-v072.md) and [activity query contract](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/activity-browser-v070.md).
