# WatchGuard v0.7.18 — native TV focus animation

- Animate Watchlists as TV remote focus enters and leaves the tab, with the same zoom duration and easing as native Favorites.
- Keep the existing 1.3× focused size and skip the animation when reduced motion is enabled.
