# WatchGuard v0.7.8 — Clearer watchlist actions and Jellyfin 12.4

Saved titles now show a bookmark with a minus on the detail-page Watchlist button, matching cards and menus. The turquoise active styling and “Remove from Watchlist” label remain. Removing a membership only changes your personal watchlist.

Jellyfin Server/Web 12.4.0 joins 12.2.0 and 12.3.0 in the integration matrix. The same package retains minimum ABI 12.2.0.0 and Jellyfin 12.2 dependencies. Runtime API, native deletion contracts, authorization and actual guard attachment remain independently checked.

See the [installation guide](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/README.md), [compatibility evidence](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/compatibility-v078.md) and [protection boundaries](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/compatibility-capabilities.md).
