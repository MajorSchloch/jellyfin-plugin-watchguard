# WatchGuard v0.7.3 — Jellyfin 12.3 compatibility

Adds explicit support for Jellyfin Server/Web 12.3.0 while retaining 12.2.0 support. Native deletion enforcement attaches only on these verified host versions and still requires the exact controller, method signatures and HTTP routes. Unknown versions remain unsupported.

The same plugin artifact targets Jellyfin ABI 12.2.0.0 and .NET 10; no dependency or storage-format migration is required. Watchlists navigation, activity queries, authorization, approvals and deletion behavior are unchanged.

See the [compatibility review and qualification](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/compatibility-v073.md) for exact official and LinuxServer images, native browser checks and limitations.
