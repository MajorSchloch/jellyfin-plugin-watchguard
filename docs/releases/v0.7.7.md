# WatchGuard v0.7.7 — Native plugin listing

WatchGuard’s Jellyfin plugin listing now uses a plain-language description, the WatchGuard artwork and concise revision summaries. The catalog and installed plugin describe the same features. Historical entries keep their original package URLs, checksums, timestamps and minimum ABI.

The native catalog installer downloads and caches the image for installed plugin cards and details. Existing installations receive the new runtime description after upgrading and restarting. Jellyfin controls the responsive layout: its details page hides the image on narrow screens; catalog and installed cards still display it. No custom details page is added.

Watchlists, activity, compatibility checks and optional deletion protection are unchanged. Server/Web 12.2.0 and 12.3.0 remain qualified; minimum ABI is 12.2.0.0 and the runtime targets .NET 10. Protection boundaries remain in settings and documentation.

See the [installation guide](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/README.md), [catalog maintenance and verification](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/catalog-listing-v077.md) and [compatibility policy](https://github.com/MajorSchloch/jellyfin-plugin-watchguard/blob/master/docs/compatibility-capabilities.md).
